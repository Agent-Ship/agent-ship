# agentship (meta-package)

One install for the everyday stack: `pip install agentship` pulls the kernel (`agentship-core`), the default engine (`agentship-langgraph`), and the CLI (`agentship-cli`). Pillar extras (`[mcp]`, `[memory]`, `[observability]`, `[service]`, `[all]`) are placeholders that fill in as each pillar phase lands.
