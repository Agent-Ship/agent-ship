# The AgentShip framework, from PyPI.
#
# This used to install the framework editable from a sibling checkout, because it was not
# published. It is now — 0.0.2 — and the sibling paths only ever resolved on a machine with
# both repositories side by side, so CI could not install this repo at all: pip reported
# "../agentship/packages/agentship-core is not a valid editable requirement" and stopped.
#
#     python -m venv .venv && source .venv/bin/activate
#     pip install -r requirements-dev.txt        # or `make install`
#
# Pinned exactly. The six ship in lockstep and are only ever tested together, so a mixed set
# is a combination nobody has run.

agentship-core==0.0.2
agentship-langgraph[mcp]==0.0.2
agentship-cli==0.0.2
# The OTel span-tree + exporters (console/Opik/LangFuse/LangSmith).
agentship-observability==0.0.2
# `[serve]` adds uvicorn: the service demo boots a real server on a loopback port rather than
# relying on TestClient, because "the ASGI app starts" is part of what it claims to show.
agentship-service[serve]==0.0.2

# NOT here: agentship-voice. It is unpublished while the voice phase lands, so the voice demo
# and its tests skip on a clean install rather than failing — `pytest.importorskip` in
# tests/test_voice.py. Install it from a sibling checkout to run them:
#     pip install -e ../agentship/packages/agentship-voice[pipecat]

pytest>=8
pytest-asyncio>=0.24

# Cassette record/replay. The default `make test` replays committed recordings with no
# key and no network; `make record` re-records them. Credentials are redacted on write
# (see tests/conftest.py), so cassettes are safe to commit.
pytest-recording>=0.13

# Read-back for the live observability slice: query each hosted backend's API to confirm the
# trace landed. httpx (Opik/LangFuse REST) is already a framework transitive dep; langsmith is
# the LangSmith SDK the read-back uses.
langsmith>=0.1

# gradio was REMOVED. The browser UI is now AgentShip Studio, served by the service
# itself at /studio (`make ui` opens it), so this repo no longer ships a UI of its
# own. Dropping gradio also unpins pydantic, which it held at <=2.12.3.

# Firecrawl backs the built-in web_search + scrape_url tools when FIRECRAWL_API_KEY is set (free
# tier at https://firecrawl.dev). It's what lets the deep-research agent actually search the web
# and read full pages. Optional: without it (and without a BRAVE_API_KEY) those tools return an
# actionable setup message and agents answer from model knowledge.
firecrawl-py>=4
